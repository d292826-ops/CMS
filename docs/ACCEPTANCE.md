# Результаты проверки

Проверено на изолированном SQLite-адаптере D1 реальных серверных модулей; тесты не меняют рабочую базу.

| Проверка | Результат |
|---|---|
| HALF_UP, точность ввода, запрет отрицательных количеств | Пройдено |
| Копеечные возвраты и отмена возвратов с нулевой стоимостью | Пройдено |
| Полночь Камчатки и неделя понедельник–воскресенье | Пройдено |
| Все контрольные суммы текущего демо-месяца | Пройдено |
| Нулевые / частичные бюджеты, скрытие несопоставимого сравнения | Пройдено |
| Серверные ограничения оператора и финансиста | Пройдено |
| Запрет изменения рабочих ролей из demo, отказ анонимным в рабочем доступе | Пройдено |
| Проведение, неизменность исторической цены и повтор ключа запроса | Пройдено |
| Два конкурентных возврата сверх количества | Один проходит, второй отклонён |
| Отмена исходной выдачи с проведённым возвратом | Отклонена |
| Недопустимая вторая строка | Документ не создан |
| Сохранение бюджета из устаревшего редактора | Отклонено |
| Недопустимые единицы топлива, изменение использованной единицы | Отклонено |
| Реальная XLSX-структура и числовые ячейки | Пройдено; файл прочитан openpyxl |
| Восстановление копии в чистую базу и внешние ключи | Пройдено |

Контрольные суммы: КАМАЗ — 25 200 ₽; ГАЗель — 7 000 ₽; здание — 14 250 ₽. Итого — 46 450 ₽. План — 49 000 ₽, остаток — 2 550 ₽. Материалы — 21 000 ₽, жидкое топливо — 20 200 ₽, газ — 5 250 ₽. Топливо по видам: 200 л ДТ, 80 л АИ-95, 150 л пропана.

Проверка TypeScript и production-сборка выполняются перед сохранением версии. Браузерная / визуальная приёмка, ежедневный автоматический запуск резервирования и production-нагрузка 20 пользователей / 100 000 строк пока не проверены или не подключены. Ориентир загрузки до 3 секунд не заявляется достигнутым без измерений.

Дополнительно: потоковая XLSX-выгрузка 100 000 строк в локальном Node завершилась за 2,43 секунды; измеренный максимум JS heap — 16,33 MB. ZIP проверен на CRC, Excel прочитан openpyxl: 100 005 строк с заголовками и итогом. Это измерение генератора файла, без сетевой задержки и чтения production D1; оно не является проверкой SLA дашборда.

Публичная демонстрация: 18 локальных проверок пройдены. Посетитель без аккаунта получает отдельные вымышленные примеры; проверены дашборд, топливо, бюджеты, журнал, карточки документов и XLSX. Рабочая база, редактируемое демо сотрудников, пользователи, аудит, резервные копии и все операции записи гостям недоступны. Проверен запрет захвата роли первого администратора посторонним.
