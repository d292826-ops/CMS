# ЦМС — открытая демонстрация

Автономный сайт на HTML, CSS и JavaScript для GitHub Pages. Посетителю не нужны аккаунты GitHub или ChatGPT, регистрация, сервер или установка приложения.

В демонстрации доступны дашборд расходов, выдачи и возвраты, справочники водителей, подразделений и материалов, топливо и газ, бюджеты, фильтры, карточки документов и выгрузка Excel.

Все примеры вымышлены. Даты примеров рассчитываются относительно текущего месяца по времени Камчатки. Это версия для просмотра: данные не редактируются и не отправляются в сеть. Рабочая база предприятия не подключена.

## Состав

- `index.html` — страница;
- `style.css` — оформление;
- `script.js` — интерфейс, примеры, расчёты и экспорт XLSX;
- `favicon.svg` — значок сайта;
- `.nojekyll` — отключение обработки Jekyll.

Внешних библиотек, CDN, шрифтов, аналитики, cookies и серверных API нет. Файлы можно открыть локально через `index.html` или разместить на статическом хостинге. На GitHub все пути относительные и поддерживают префикс `/CMS/`.

## Публикация

В Settings → Pages выберите Deploy from a branch, ветку `gh-pages`, папку `/(root)` и Save. После успешного развёртывания адрес проекта: `https://d292826-ops.github.io/CMS/`.

Основной серверный проект сохранён в ветке `main`. Ветка `gh-pages` содержит автономную публичную демонстрацию.

Контрольные суммы текущего месяца: КАМАЗ — 25 200 ₽; ГАЗель — 7 000 ₽; здание — 14 250 ₽. Всего — 46 450 ₽. План — 49 000 ₽. Остаток — 2 550 ₽. Топливо: ДТ — 200 л, АИ-95 — 80 л, газ — 150 л.
