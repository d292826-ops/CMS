# Отдел снабжения — учебный MVP

Сайт работает в обычном браузере. Это дипломная демонстрация на вымышленных данных: каждый браузер хранит собственный набор. Общей серверной базы, настоящего входа и подключения к 1С сейчас нет.

## Открыть и запустить

На этом Mac откройте [сайт](http://127.0.0.1:4173/#/). Если он недоступен, дважды нажмите **Запустить сайт.command** в этой папке. Откроется окно Терминала и браузер. Терминал нужно оставить открытым; остановка — Ctrl+C в этом окне.

Скрипт использует подготовленную локальную Node.js 24 из `../.tools/node/`, при её отсутствии — установленную Node.js 24. После копирования репозитория на другой компьютер установите Node.js 24; локальная среда `.tools/` и зависимости намеренно не хранятся в git. Скрипт собирает сайт, при необходимости устанавливает зависимости из lockfile и запускает локальный просмотр. Никаких паролей или настроек для демо не требуется.

Разработка: `npm run dev` в `app/`, адрес http://127.0.0.1:5173/ . Собранная версия: `npm run build`, затем `npm run preview`, адрес http://127.0.0.1:4173/ . Первый запуск после клонирования: `npm ci`.

## Посмотреть основной процесс

1. На старте выберите **М1 — механик**, нажмите «Начать демонстрацию». Откройте «Создать заявку»: машина А, номенклатура П-001, 2 шт, отправить. В карточке видны автор М1 и ответственный К1.
2. В шапке «Выбрать участника» → **К1 — кладовщик** → «Очередь склада» → созданная заявка → подготовка выдачи. Фактический получатель **Д1**. Подготовка не списывает запас; «Подтвердить фактическую выдачу» → «Провести выдачу» списывает2 шт.
3. Выберите **Д1 — водитель** → «Мои заявки» → «Мне выдано» → документ → подтвердите получение. Это не создаёт второе списание. Другой водитель Д2 не подтверждает этот документ.
4. **Ф1 — финдиректор** → «Финансовый разбор», машина А / ноябрь2026. До выдачи доход5 000 ₽, расход1 000 ₽, результат4 000 ₽. После выдачи расход2 000 ₽, результат3 000 ₽. «Запчасти» → источник → документ → печать. «Назад к списку» возвращает прежнюю статью.
5. **К1** → документ выдачи → полный возврат → подтвердить фактическое возвращение. Запас снова10 шт; обратный расход−1 000 ₽, результат А снова4 000 ₽. Исходная выдача и подтверждения остаются в истории.

«Начать демонстрацию заново» заменяет только учебные изменения текущего браузера после подтверждения. В «Учебных примерах» есть неизвестные доходы/цена, нехватка,20 операций, цена каталога700 после выдачи по500, возврат другого месяца. Ошибки воспроизводятся по [инструкции](tests/browser-checks.md).

## Дашборды финансового директора и собственника

Выберите финансового директора или собственника → «Финансовый разбор» → «Показать пример автопарка» → «Открыть пример автопарка». Подтверждение заменяет текущие учебные изменения, сохраняя роль; отмена ничего не меняет.

Выберите самосвал, автокран или экскаватор. Круговая диаграмма показывает плюс/минус по учтённым статьям, полосы — доходы от перевозок, аренды или работ, столбцы — три месяца. У экскаватора в ноябре вымышленный убыток 75 000 ₽. Точные операции доступны по кнопке под доходами. Диаграммы работают и с прежним набором; неизвестные суммы не становятся нулями.

## Повторить технические проверки

```sh
npm test
npm run build
```

Браузерный тест использует установленный Google Chrome с отдельным временным профилем и протоколом отладки. Никаких библиотек автоматизации не устанавливает. Запустите Chrome для QA отдельно (не свой рабочий профиль), локальный сайт и затем:

```sh
SUPPLY_BASE_URL=http://127.0.0.1:4173/ node tests/browser/acceptance.mjs
SUPPLY_BASE_URL=http://127.0.0.1:4173/ node tests/browser/review-fixes.mjs
SUPPLY_BASE_URL=http://127.0.0.1:4173/ node tests/browser/dashboard.mjs
SUPPLY_BASE_URL=http://127.0.0.1:4173/ node tests/browser/traceability.mjs
SUPPLY_BASE_URL=http://127.0.0.1:4173/ node tests/browser/load-contexts.mjs
SUPPLY_BASE_URL=http://127.0.0.1:4173/ node tests/load-static.mjs
```

Ожидаемый порт отладки9224. Из корня репозитория `node app/tests/audit.mjs` проверяет исходники и игнорирование секретов. Тесты браузера предназначены только для отдельного QA-профиля: они явно сбрасывают его учебные данные.

Пример запуска QA Chrome на этом Mac:

```sh
'/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' --headless=new --disable-gpu --no-first-run --remote-debugging-address=127.0.0.1 --remote-debugging-port=9224 --user-data-dir=/private/tmp/supply-qa-profile about:blank
```

Стек интерфейса: React19.3.1, TypeScript6.0.3, Vite8.3.8, Tailwind4.3.5. Версии зафиксированы в lockfile; Inter и иконки/лицензии локальные. Дизайн — [дизайн.md](../дизайн.md), объём — [техническое-задание.md](../техническое-задание.md).
