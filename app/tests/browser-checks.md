# Браузерная проверка учебного MVP

Старт: http://127.0.0.1:5173/#/ . Только синтетический набор. Сначала «Начать демонстрацию заново» → подтвердить, затем выбрать участника и нажать «Начать демонстрацию». М1 — механик, Д1/Д2 — разные водители, К1 — кладовщик, Ф1/С1 — руководство.

## Основной цикл

1. М1 → «Создать заявку», машина А, «Найти в номенклатуре» → П-001 → выбрать → 2шт → отправить. Карточка: М1, К1, VIN машины А. Запомнить номер.
2. «Выбрать участника» → К1 → очередь → нужная заявка → подготовка → получатель Д1. «Подготовить документ» сохраняет документ без движения. Подтвердить фактическую передачу → провести. Запас10→8; расход1000₽.
3. Д2 не может подтвердить документ Д1. Д1 → «Мои заявки» → «Мне выдано» → документ → сверить → подтвердить. Повтор не списывает запас снова. Текст «Есть расхождение» не подтверждает получение.
4. Ф1 → «Финансовый разбор» → А/ноябрь2026: доход5000, расход2000, результат3000. Запчасти → источник. Назад возвращает тот же месяц и статью. Печать не проводит операцию.
5. К1 → исходная выдача → полный возврат → подтвердить. Запас8→10; обратный расход−1000₽. Ф1: результат4000. Б:−400. Д1 больше не подписывает возвращённую выдачу; старые подтверждения сохранены.

## Форма и переходы

Пустая отправка показывает три подсказки, фокус на машине. Исправление машины убирает только её подсказку. 0/минус/текст запрещены; дробные штуки запрещены, 1,5м допустимы. Каталог сохраняет черновик. Уход по меню или кнопкой браузера «Назад» предлагает остаться либо отменить ввод. В первом случае поля/роль сохраняются, во втором операция не создаётся. Выбор другой машины меняет VIN. Машина без VIN сохраняет потребность, но физическая выдача запрещена.

## Подготовленные наборы

На старте «Учебные примеры»: основной, нехватка1шт, неизвестный доход, неполный расход, неизвестная цена, известные нули,20строк топлива. Загрузка требует подтверждения и заменяет только учебные изменения текущего браузера. При нехватке заявка сохраняется с отметкой; выдача блокируется. При неизвестной цене фактическая выдача допустима, сумма — «Нет данных».

## Ошибки по адресу

Сначала выберите роль в обычном режиме; затем откройте адрес с `?case=КОД` перед `#/...`. Контрольные режимы не повреждают сохранённый набор. Для выхода «Обычная демонстрация»; при повреждённом сохранении — явно восстановить исходный набор.

## Видимость и печать

Механик/водитель: без цен/сумм в обычном и печатном документе; доступны собственные заявки или своё получение. Кладовщик: складские суммы, без доходов и результата машины. Ф1/С1: финансовое чтение, без кнопок передачи/получения за другого участника. Демо-переключатель не является защитой настоящих сведений. SOURCE не получает складских действий. Печать использует стандартный диалог браузера; отмена/повтор не меняют revision.

Проверить клавиатуру, фокус диалогов, ширины390/1440, прокрутку таблиц и20строк, прямые ссылки, обновление. Неподготовленный месяц не означает ноль. Реальный ноль показан числом, null — «Нет данных», неприменимое поле — «Не применяется», некорректная сумма — «Ошибка данных».
